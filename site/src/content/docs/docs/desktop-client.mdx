The desktop client is a Tauri application for macOS and Windows. Its React interface drives the same Rust runtime used by the CLI, including sessions, approvals, memory, provider settings, usage history, and plugin management.

The runtime boundary remains the Rust agent core: the desktop product direction can build on the same session, provider, tool, approval, storage, memory, plugin, and MCP concepts used by the library and CLI.

## Current Status

- Tauri provides the native shell and Rust command boundary.
- Vite, React, and TypeScript provide the tested frontend.
- Tagged releases build Windows installers and macOS application bundles through GitHub Actions.
- Local development and production builds use the commands in the repository `desktop/` directory.

```bash
cd desktop
npm ci
npm test
npm run tauri dev
# or build a local package
npm run tauri build
```

Published packages are attached to matching GitHub Releases. macOS packages are not currently notarized; follow the release notes for the explicit local verification step instead of assuming an operating-system trust signature.
